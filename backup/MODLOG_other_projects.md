## Задача 2026-11-02: реальное торможение двигателем / поведение трансмиссии
Пользователь: при понижении (3→2) нет ощутимого торможения двигателем; горный тормоз на отдельной кнопке.
Цель: двигатель тормозит пропорционально передаче/оборотам, с выжатым сцеплением — нет.

### Route (выбран)

   + `flywheel_inertia` (1.61+). Свой локальный .scs, переопределяющий файлы двигателей.
   Источник: https://modding.scssoft.com/wiki/Documentation/Engine/Units/accessory_engine_data

   Нельзя подать момент напрямую; тормозная ось не годится (стоп-сигналы).

### Базовый замер 2026-11-02 (logs/20261102-132240_baseline.csv, без модов двигателя)
- Двигатель D17A780 (dlc_volvo_fh_2024): torque 3800, volume 17.3, rpm_limit 2000, engine_brake 1.5,
  resistance_torque/flywheel_inertia НЕ заданы → default 346 N·m @2000. Коробка ATO3812G ASO (14 вперёд, 2 crawl),
  дифф 3.08, радиус колеса ~0.512 м (из rpm/speed). Telemetry gear: 1-2 = C1/C2, 3 = 1-я, 4 = 2-я … 14 = 12-я.
- Масса автопоезда по разгону на полном газу (4 участка, разные передачи): **~87 т** (груз — log stacker, тяжеловес).
  Совпадение по передачам подтверждает, что игра отдаёт момент ровно по def.
- Торможение двигателем (m·Δa/(i/r), Δa = накат на передаче − накат со сцеплением ~0.06 m/s²):
  ~165 N·m @1000, ~230 @1500, ~270 @2000, ~400 @5500 rpm. Т.е. ≈ resistance × rpm/2000 × ~0.8, с насыщением выше 2000.
  Порядок величины близок к реальному трению дизеля 17 л (~300 N·m @2000 без VEB) — **трение само по себе не занижено**.
- Главная нереалистичность: 8-я → 2-я на 41 км/ч (ошибка слота H) — игра включила, бросок сцепления 0.27 с,
  обороты 500 → **6118** (лимит 2000), скорость −0.2 км/ч (нет рывка), торможение лишь 0.32 m/s², без повреждений.
  Синхронизация оборотов при бросании сцепления мгновенная (500→2040 за 0.2 с на 37 км/ч, без рывка).
- Вывод: ощущение «торможения при понижении» в реальности = рывок при сцеплении + VEB (у Volvo часто авто на сброс газа).
  Data-мод на resistance_torque даст мало (при 87 т — почти незаметно). Основное — внешняя программа.

### Решение пользователя 2026-11-02: делаем пункты 1 (блок передачи с перекрутом), 3 (заглохание), 4 (авто-VEB); 2 (рывок) — не нужен
Программа `drivetrain\gearbox\real_gearbox.py` (запуск `Real Gearbox.cmd`, `--dry` = без клавиш):
- блок: controls.sii gearN = `(joy.bN?0 & !(keyboard.f8?0))` — программа держит F8, пока рычаг в «запрещённом» слоте
  (прогноз оборотов > 2300 или против направления); снимает блок при прогнозе < 2200 и выжатом сцеплении. Звук grind.wav.
  Без программы шифтер работает как раньше. Клавиши шлются только когда ETS2 — активное окно.
- заглохание: педаль сцепления < 0.15, на передаче, колёса держат мотор < 300 об/мин 0.6 с → клавиша F (engine).
- авто-VEB: engbrakeup = K, engbrakedwn = U (добавлены в controls.sii); вкл через 0.4 с без газа на передаче > 12 км/ч, > 950 об/мин.
- patch_controls.py (backup → backup\controls\*.gearbox-patch, `--restore`), применён 13:38 при закрытой игре.
- Ввод: pygame-ce (SDL) — R5 Base 128 кнопок, кнопка SDL = ETS2 joy.bN − 1; TruckShift b0 = range, b1 = split.
- Раскладка volvo_12_2: impulse 2 = C, 3 = R, 4/5/6 = 1-4 / 2-5 / 3-6; telemetry slot @568 = impulse (подтверждено).
- Полярность range/split учится по событиям смены передачи (polarity.json): split/range — ПРЕДВЫБОР, применяются при
  переключении, сырое положение переключателя между переключениями ничего не доказывает. До обучения блок только по направлению.
- Телеметрия: байт 585 «engine» ненадёжен → двигатель = rpm > 250. motor_brake @583 — не проверен.
- Передаточные: ratios.json (дефолт из def + дообучение по rpm/скорости).
