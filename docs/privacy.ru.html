Политика конфиденциальности

Обновлено: 26 ноября 2026 г.

Эта политика распространяется на приложение kanal15-publisher — личную консольную утилиту автора проекта «Канал 15» («мы», «инструмент») — и на сайты проекта «Канал 15», размещённые по адресу straysouler-svg.github.io/kanal15.

1. Что делает приложение

Приложение загружает игровые видео, созданные автором, с личного компьютера автора на его собственный аккаунт TikTok через официальный TikTok Content Posting API. TikTok Login Kit используется исключительно для авторизации собственного аккаунта автора по протоколу OAuth 2.0.

2. Какие данные мы собираем

Никакие. Приложение не собирает, не передаёт, не хранит и никому не раскрывает персональные данные пользователей. Оно работает локально на компьютере автора и обращается только к официальным API TikTok. В приложении нет учётных записей пользователей, форм регистрации и встроенной аналитики.

3. Аналитика сайта

На страницах сайта «Канал 15» установлен счётчик Яндекс.Метрики (ym 114361078), который собирает анонимную обобщённую статистику посещений (просмотры страниц, клики по ссылкам). Счётчик может устанавливать собственные cookies под ответственность Яндекса и в соответствии с его политикой конфиденциальности. Он не позволяет нам идентифицировать вас лично и не загружается самим приложением kanal15-publisher. Вы можете заблокировать его любым блокировщиком контента — работа сайта от этого не пострадает.

4. Токены и учётные данные

Токены доступа и обновления (access/refresh tokens), выданные TikTok, хранятся локально на компьютере автора и никогда не передаются третьим лицам. Они используются исключительно для аутентификации запросов к API TikTok и могут быть отозваны в любой момент в настройках аккаунта TikTok.

5. Третьи лица

Приложение взаимодействует только с TikTok (open.tiktokapis.com). В нём нет аналитики, рекламы, трекеров, cookies и сторонних SDK. Данные никому не продаются, не сдаются в аренду и не передаются ни для каких целей, включая коммерческие.

6. Хранение и удаление данных

Поскольку данные пользователей не собираются, хранить и удалять нечего. Загруженные видео находятся на собственном аккаунте автора в TikTok и регулируются политикой конфиденциальности TikTok. Авторизацию TikTok можно отозвать в любой момент в настройках аккаунта.

7. Безопасность

Приложение хранит учётные данные только на локальном компьютере автора, общается с TikTok исключительно по HTTPS, а его исходный код полностью открыт и доступен для проверки в публичном репозитории.

8. Конфиденциальность детей

Приложение не предназначено для детей и не обрабатывает никакие данные детей. Это личный инструмент взрослого автора.

9. Изменения политики

При изменении политики обновлённая версия публикуется на этой странице с новой датой «обновлено». О существенных изменениях дополнительно сообщается в репозитории проекта.

10. Контакты / оператор данных

Оператором данных является физическое лицо — автор проекта «Канал 15». Вопросы по этой политике: создайте issue на github.com/straysouler-svg/kanal15 или напишите в Telegram: @kanal15_publisher_bot.
