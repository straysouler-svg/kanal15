Privacy Policy

Last updated: November 26, 2026

This policy covers the application kanal15-publisher — a personal command-line tool operated by the author of the Kanal 15 project ("we", "the tool") — and the Kanal 15 project websites hosted under straysouler-svg.github.io/kanal15.

Download as PDF

1. What the application does

The application uploads gameplay videos created by the author from the author's own computer to the author's own TikTok account, using the official TikTok Content Posting API. TikTok Login Kit is used solely to authorize the author's own account via OAuth 2.0.

2. Data we collect

None. The application does not collect, transmit, store or share any personal data of any user. It runs locally on the author's machine and communicates only with TikTok's official API endpoints. There are no user accounts, no registration forms and no analytics inside the application.

3. Website analytics

The Kanal 15 landing pages use the Yandex.Metrika counter (ym 114361078) to measure anonymous, aggregated visit statistics (page views, link clicks). This counter may set its own cookies under Yandex's responsibility and privacy policy. It does not identify you personally to us, and it is not loaded by the kanal15-publisher application itself. You can block it with any content blocker without affecting the site.

4. Tokens and credentials

OAuth access and refresh tokens issued by TikTok are stored locally on the author's computer and are never shared with any third party. They are used exclusively to authenticate requests to the TikTok API and can be revoked at any time in the TikTok account settings.

5. Third parties

The application interacts only with TikTok (open.tiktokapis.com). No analytics, advertising, tracking, cookies or third-party SDKs are used by the application. No data is sold, rented or transferred to anyone, for any purpose, including commercial purposes.

6. Data retention and deletion

Since no user data is collected, there is nothing to retain or delete. Uploaded videos reside on the author's own TikTok account and are governed by TikTok's own privacy policy. TikTok authorization can be revoked at any time in TikTok account settings.

7. Security

The application stores its credentials only on the author's local machine, communicates with TikTok exclusively over HTTPS, and its full source code is open for review in the public repository.

8. Children's privacy

The application is not directed at children and does not process any data of children. It is a personal tool operated by its adult author.

9. Changes to this policy

If this policy changes, the updated version will be published on this page with a new "last updated" date. Material changes will be additionally noted in the project repository.

10. Contact / data controller

The data controller is the individual author of the Kanal 15 project. Questions about this policy: open an issue at github.com/straysouler-svg/kanal15 or message @kanal15_publisher_bot on Telegram.
