# Выпуск рации для других игроков

Черновик 2026-11-04. Повод: пользователь хочет дать рацию другу Кириллу (позывной «СидиПосиди»), а потом выложить в общий доступ. Связано с планом монетизации (память, 2026-11-04).

## 1. Позывной игрока

**Сейчас:** 99 записей из 641 обращаются к «Железяке». Это все 54 приветствия игроку, 12 из 69 «принял», 9 из 10 «опять встретились», 5 «пока», 5 «повтори», ещё около 14 разных и одна сценка. По движкам: gpt-audio 74, ElevenLabs 16, клон Сороки 9.

**Решение: два слоя.**

1. **Нейтральная база.** У каждой записи с позывным есть пара без имени: «Здорово, брат!», «О, новенький на канале», «Слышу тебя, водила». Эта пара звучит у любого игрока. Рядом с каждой репликой в json хранится нейтральный вариант, поле `"neutral"`.
2. **Личный пакет позывного** (по желанию). Отдельная программа «Мой позывной» озвучивает именные варианты под позывной игрока его собственным ключом (OpenRouter или ElevenLabs). Около 100 реплик, примерно 1–1,5 $ у игрока. Рация берёт именную версию, если она есть, иначе нейтральную. В `config.json` поле `"player_handle"`.
   - Упрощённый вариант без ключа: каждый персонаж записывает только окрик «<Позывной>!» (15 коротких записей), он склеивается перед нейтральной фразой. Через рацию с помехами склейка почти незаметна.
3. **Распознавание.** Позывной игрока попадает в подсказку Whisper (PROMPT) и в `intents`, чтобы «<Позывной> в эфире» распознавалось как приветствие.

Пакет «Железяка» остаётся пакетом пользователя и в раздачу не идёт.

## 3. Что нельзя отдавать

- **Ключи:** `elevenlabs_key.txt`, `openrouter_key.txt`. Перед упаковкой проверка, что их нет.
- **Голос Татьяны** (Сорока: клон и записи её настоящего голоса). Только с её письменного согласия. Без согласия Сорока выпадает из раздачи или переозвучивается.
- **Служебное:** `samples/`, `audio/_backup_*`, `audio/_retired_scenes`, `*.before_*.py`, `downloads`, `tools_untrusted`, `map/extracted` (это файлы игры).

## 4. Права (подробнее см. план монетизации)

- Бесплатная раздача другу и в общий доступ (некоммерческая): ElevenLabs бесплатного тарифа и XTTS (CPML, некоммерческая) терпимы. Для продажи их нужно переозвучить.
- Музыка CC BY (Kevin MacLeod, Audionautix, Antti Luode, Sascha Ende): указать авторов в описании (`music/CREDITS.md`).
- Песни Lyria: проверить условия Google для preview-моделей.
- Карта городов: координаты получены из игры и OpenStreetMap (ODbL). Указать «© участники OpenStreetMap».

## 5. Размер

Сейчас: `audio` 1,3 ГБ, `music` 343 МБ, `models` 177 МБ. Для раздачи:
- эфир перекодировать в OGG/Opus моно (рации хватает 16–24 кГц): примерно в 10 раз меньше;
- музыку тоже в Opus, исходники Lyria не класть.

Цель: 200–300 МБ.

## 6. Порядок

1. Нейтральная база (поле `neutral` + озвучка около 100 реплик).
2. Флаг `player_handle` в рации: именная версия, если есть, иначе нейтральная.
3. Мастер настройки (кнопка, микрофон, позывной, проверка телеметрии).
4. Сборщик раздачи `tools/pack_release.py`: копирует только нужное, перекодирует, проверяет ключи и личные файлы, пишет README с установкой плагинов и благодарностями.
5. Пробная раздача Кириллу. Его отзыв, потом общий доступ.
