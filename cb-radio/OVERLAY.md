# Оверлей для стрима

Радио «Канал 15» показывает поверх игры эфир: кто говорит, субтитры реплик и «Бухгалтерию».
Всё настраивается прямо в браузере, без правки файлов.

1. Запустите рацию (CB-Radio.exe).
2. Откройте в браузере: **http://127.0.0.1:47823/setup**
3. Отметьте, что показывать (логотип, зону рации, субтитры, плашку), выберите расположение,
   масштаб и цвет — страница сама соберёт адрес для OBS.
4. В OBS добавьте источник **«Браузер»** (1920×1080), вставьте скопированный адрес.

Подсказки:
- `layout=minimal` — только субтитры, без полос и фона; `layout=bottom` — всё внизу.
- `brand=0` полностью убирает логотип «КАНАЛ 15» — если хотите только чистый эфир.
- Параметры можно править руками в адресе: `zone=0`, `subs=0`, `phone=0`, `top=0`, `bottom=0`,
  `bg=0`, `scale=0.5..2`, `accent=rrggbb` (цвет в hex без `#`).
- Страница работает только на вашем компьютере (127.0.0.1) — из интернета её не видно.
