**Источник истины.** Заголовок `scs-telemetry/inc/scs-telemetry-common.hpp` из GitHub `RenCloud/scs-sdk-plugin`, тег `V.1.12.1` (та же версия, что `vendor/scs-telemetry.dll`; SHA-256 в `vendor/README.md`). Карта: `Local\SCSTelemetry`, размер 32 КБ, тип `scsTelemetryMap_t`. Каналы SDK сверены с официальными заголовками scssdk в том же репозитории (`scs_sdk/include/common/scssdk_telemetry_*`).

## Часть 3. Проект: один источник (RenCloud вместо Funbit+RenCloud)

Код не пишем до «да» пользователя.

**Что выигрываем.**
- Один плагин в установщике вместо двух; один набор VC++-библиотек (2015–2022) вместо двух (2012 msvcr110 + 2015–2022).
- Одна точка диагностики «жду игру»: сейчас рация ждёт Funbit, а штрафы — RenCloud; два разных «игры нет» путают игрока.
- Все каналы групп А/Б уже в одной карте — нет двух карт, двух хендлов, двух соглашений о смещениях.
- Funbit-библиотека VC++ 2012 (`msvcr110.dll`) — самая старая и самая частая причина «плагин не грузится» у игроков.

**Риски.**
- `gamecheck.py` целиком построен на карте Funbit (`Local\SimTelemetryETS2`): `mapping_probe()`, `mapping_error()`, чтение game.log про `ets2-telemetry`. Всё это надо переписывать на `Local\SCSTelemetry`.
- Смещения позиции (2200/2216 вместо 40/48) и часов (64 вместо 160) в RenCloud другие; счётчик «живости» — `time` @8 (или paused @4 + time_abs @64) вместо счётчика Funbit @0. Требуют живой проверки в заезде (часть 2): не переключать источник позиции/часов без пробника.
- У действующих установок оба плагина уже стоят — ничего не удаляем.
- Плагин RenCloud пишет sdkActive/paused, но «двигатель включён» у RenCloud — `engineEnabled` @1576; по опыту Funbit байт двигателя ненадёжен (двигатель = rpm>250) — тот же приём нужен и здесь: rpm @952.
- SimHub у игроков подменяет/дублирует RenCloud (карта `Local\SHSCSTelemetry` — тот же плагин, переименованный). Приоритет чтения, как сейчас в `Fines` (свой RenCloud первым, SH — запас), сохранить.

**Безопасный порядок (по шагам, каждый отдельным релизом):**
1. Каналы группы А читаем из RenCloud, Funbit остаётся первым источником позиции/часов/двигателя/дворников. Живая сверка: пробник показывает одинаковые позицию и часы из обеих карт.
2. Переключение `Game` (state/pos/wipers) на RenCloud: Funbit-чтение оставить запасным на один релиз (если `SCSTelemetry` нет — читать Funbit). Установщик по-прежнему кладёт оба плагина.
3. Переписать `gamecheck.py` на RenCloud: probe `Local\SCSTelemetry`, диагностика «плагин не найден / не загрузился» по наличию dll и строке `SCSTelemetry` в game.log. Удаление Funbit из установщика — только после пары релизов без жалоб и по решению пользователя (у игроков на диске он всё равно остаётся).

## Сверка gamecheck.py:192 — «Memory telemetry example initialized»

Вердикт: **признак недостоверен, подтверждаю диагноз Штурмана (10.11) — с оговоркой.**

Что установлено:
- Исходники RenCloud v1.12.1 эту строку **не пишут** (проверено по `scs_telemetry.cpp`/`log.cpp` на теге V.1.12.1; строки нет и в бинарнике `vendor/scs-telemetry.dll`).
- Строка — фирменная метка примера SCS SDK «memory telemetry example»: её печатают плагины, собранные из этого официального примера. MOZA PitHouse ставит в игру именно такой SDK-плагин (по [инструкции MOZA](https://support.mozaracing.com/en/support/solutions/articles/70000627859-euro-truck-simulator-2) — `ETS2SharedMemoryMapPlugin32.dll`, создаёт `SCSTelemetryShared`, ср. `gamecheck.py:15`). То есть строка в game.log означает «загрузился какой-то SDK-плагин на примере», а не «загрузился именно Funbit и создал `Local\SimTelemetryETS2`».
- `gamecheck.py:192` ищет её в 40 строках после загрузки `ets2-telemetry.dll`; если MOZA-плагин грузится рядом (имя файла начинается с `ETS2Shared...`, порядок загрузки плагинов в game.log — по алфавиту: `ETS2SharedMemoryMapPlugin` раньше `ets2-telemetry`), его строка «…initialized» не должна попадать в окно… но у пользователя машина MOZA, и по диагнозу Штурмана факт ложного «ok» наблюдался 10.11. Локально подтвердить не смог: `game.log.txt` в воркспейсе нет (прочитать живой лог не вышло). Живое подтверждение — одна строка грепом по `Documents\Euro Truck Simulator 2\game.log.txt` при следующем заезде.
- Надёжный признак загрузки Funbit-плагина — не лог, а сама карта: `OpenFileMappingW("Local\SimTelemetryETS2")` (уже есть `mapping_error()` в `gamecheck.py:141`). Рекомендация: выпилить проверку по строке лога, опираться на probe карты + наличие dll в `bin\win_x64\plugins`.
