# «Канал 15» в Steam как ранний доступ (альфа) — пошаговая инструкция

Решение пользователя 2026-11-10: не ждать полного плана, выкладываться в Steam как альфа (Early Access)
на живом MVP и вести историю проекта публично. Заменяет осторожный план от 08.11 (релиз декабрь–январь):
сама страница и процесс становятся частью истории («проекту неделя — а он уже в Steam»).

## Этап 0. Решения до старта (1–2 дня, бесплатно)

- **Модель:** базовое приложение БЕСПЛАТНО (F2P), платные DLC (паки персонажей, сюжеты) — потом, отдельными app credit ($100 за DLC). Для альфы — только база.
- **Название в Steam:** проверить занятость «Kanal 15». Рабочий вариант: «Kanal 15 — CB Radio Companion for ETS2». Подзаголовок/короткое описание: «мультиплеер для интровертов».
- **Рейтинг IARC (бесплатный, внутри партнёрки):** в эфире есть мат → честно отвечаем в опроснике, получим Mature/18+ в части регионов. Это влияет на видимость (например, Германия). Решить: мат остаётся (взрослая аудитория дальнобоя) — отразить в описании.
- **Права на контент (критично, проверить ДО подачи):**
  - ElevenLabs: тариф Creator включает коммерческую лицензию — база ок. Сохранить скриншоты тарифа и условий.
  - XTTS-клон Сороки (CPML, некоммерческая) — в Steam-сборку НЕ идёт (решено 08.11): Steam-база = 17 актёров без Сороки.
  - Песни Lyria — условия Google не проверены: в Steam-сборку не класть до проверки (песни отключаются отдельно).
  - Музыка Commons — атрибуции в `music/CREDITS.md` уже есть; CC BY требует указания автора в продукте — добавить экран/файл «Credits» в сборку.
  - Свой код, свои тексты, свои ФИО — чисто.
- **Юридическая сторона (самый рискованный пункт, не откладывать):** Steamworks требует налоговое интервью (W-8BEN), банковский счёт с SWIFT для выплат и верификацию личности. Из РФ: оплата $100 взноса и получение выплат — отдельная задача (зарубежная карта/счёт, самозанятость vs ИП). Действие: до старта выбрать схему, при сомнениях — консультация бухгалтера. Без этого пункта страница не откроется.

## Этап 1. Регистрация Steamworks (день 1)

1. Завести отдельный Steam-аккаунт для проекта (или использовать существующий) + включить Steam Guard.
2. Регистрация на partner.steamgames.com: данные (физлицо/ИП), налоговое интервью, банковские реквизиты.
3. Оплатить Steam Direct fee **$100** (возвращается после $1000 выручки; для F2P-базы выручки не будет до DLC — считать взносом в историю).
4. Верификация личности (паспорт) и банка — по срокам 08.11: онбординг 15–30 дней. Новым партнёрам релиз первой игры доступен не раньше чем через ~30 дней после регистрации (анти-фрод холд Valve).

## Этап 2. Параллельно, пока идёт онбординг (недели 1–4): контент страницы

- **Капсулы** (обязательные размеры: header 460×215, small 231×87, main 616×353, library 600×900, hero) — Художник, стиль «стол с личными делами» уже утверждён.
- **Скриншоты ≥5:** игра + оверлей рации, журнал эфира, шкала дружбы. Снять вживую (пользователь в игре) + Художник оформляет рамку.
- **Трейлер** (желательно, не обязательно): 60–90 с — Монтажёр из стрим-записей, голос эфира поверх.
- **Описание RU + EN** (короткое + развёрнутое + блок «Почему ранний доступ»): пишет Летописец в утверждённом стиле, EN — тот же текст переводом. Правила EA: честно, что есть сейчас; планы без дат и обещаний («в разработке: новые страны, больше персонажей» — можно; «выйдет в марте» — нельзя).
- **Теги:** Simulation, Driving, Atmospheric, Conversation, Singleplayer (+ Truck, Relaxing).
- **Системные требования:** Windows 10 x64, ETS2 (любая актуальная версия), 2 ГБ RAM, 3 ГБ диск, микрофон опционально.

## Этап 3. Страница «Скоро выйдет» (как только онбординг пройден)

1. Заполнить страницу, отправить на ревью (3–5 рабочих дней).
2. После одобрения — публикация «Скоро выйдет». **Обязательный минимум 14 дней до релиза** (правило Valve).
3. С этого дня — публичная история: ссылку в Telegram/форумы, сбор вишлиста. Глашатай готовит пост «проекту неделя, а он уже в Steam» — это сильная рамка.

## Этап 4. Депо и сборка (параллельно с «Скоро выйдет»)

1. Установить SteamPipe SDK (steamcmd) на эту машину.
2. Создать depot Windows x64; содержимое = наша сборка onedir (`release\neutral\CB-Radio` + модель whisper). Steam-вариант: автообновление выключено (обновляет Steam; уже предусмотрено в плане 08.11), канал обновлений — ветки Steam (default = stable).
3. Установка плагина телеметрии: Steam-версия при первом запуске предлагает скопировать `scs-telemetry.dll` в папку ETS2 (установщик уже умеет искать игру через реестр/Steam).
4. Тест установки через steamcmd локально (`steamcmd +app_install`), затем ревью сборки Valve (3–5 рабочих дней): проверяют, что запускается и не требует лишних прав. Нюанс: рабочая папка рации в %LOCALAPPDATA% — ок; запись в папку ETS2 только по кнопке пользователя.
5. Релизная ветка: default → всем; отдельная beta-ветка для тестеров (Данил/Кирилл) — бесплатно и удобно, коды не нужны.

## Этап 5. Релиз альфы

- Условия: онбординг пройден (~30 дней), «Скоро выйдет» отвисел ≥14 дней, сборка одобрена.
- День релиза: кнопка «Release», пост в Telegram, обновление README/GitHub со ссылкой на Steam, публикация на форумах (Глашатай, утверждённый стиль).
- После: вести историю обновлений прямо на странице Steam (новости каждой версии — это и есть «история проекта»).
