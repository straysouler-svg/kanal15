# Промт для Клода: совет по режиму конвоя (12.11.2026)

Привет! Прошу совета по архитектуре новой фичи — хочу оценить идею до того, как садиться писать код.

**Контекст.** Я делаю «Канал 15» — локальный мод-компаньон для Euro Truck Simulator 2: рация, в которой 18 вымышленных дальнобойщиков разговаривают с игроком. Всё работает локально на ПК игрока: микрофон → whisper-распознавание речи → интенты → персонажи отвечают озвучкой (ElevenLabs / gpt-audio) через эмулятор радиоэфира. Никаких серверов и сети. Есть механика «дружбы» (bonds.json) — персонажи постепенно узнают игрока, отношение меняется.

**Идея: режим конвоя.** Друг (или зритель стрима) подключается голосом через Discord и разговаривает с нашими водителями наравне с игроком. Рация при этом в сеть НЕ выходит — она просто слушает второй аудиоканал и отвечает в него же:

- Голос друга из Discord выводится на виртуальный аудиокабель (VB-Cable) → рация видит его как второй микрофон, второй whisper-поток.
- Ответы водителей миксуются на второй кабель, назначенный микрофоном Discord → друг слышит водителей.
- Разделение говорящих «бесплатное»: физический микрофон = игрок, кабель = друг, диаризация не нужна.

**Что я вижу как новые задачи:**
1. Личность гостя: позывной в конфиге, сценка представления, механика знакомства (чужой → знакомый → свой) — тот же путь, что у игрока.
2. Отдельный журнал дружбы для гостя (чтобы не наследовал отношения игрока).
3. Адресация ответов: спросил друг — отвечают другу по имени.
4. У друга нет тангенты (кнопки PTT) — вход по VAD с порогом от фонового шума.
5. Приватность: личные реплики (внутренние, только для владельца) в канал гостя не миксуются.
6. Риски: эхо (рация слышит сама себя из колонок), задержка Discord 100–300 мс, ложные срабатывания VAD, нагрузка двух whisper-потоков на CPU.

**Планируемые этапы:**
0. Стенд без сети: кабель петлёй на этот же ПК, плеер с записью голоса — проверить разделение говорящих.
1. Односторонний конвой: друг слышит и отвечает, дружба не пишется.
2. Полный: журнал дружбы гостя, сценки знакомства.
3. Стрим-формат: зритель из чата подключается голосом («позвони дальнобою»).
