# Памятка для Механика (куда интегрировать)

**1а «Куда едешь» с исландскими городами:**
- Группа: `reactions.intent.route` (куда едешь/куда едете/направление) — расширить варианты ответов актёров городами DLC. Вес выше для Исландии, пока DLC новое (первые недели после 10.11), потом уравнять.
- Условие выпадения: текущий маршрут игрока/встречного — исландский регион (если телеметрия даёт регион; иначе — безусловно, по весу).
- buhgalter — `reactions.intent.route.buhgalter`, своя ветка, как у «Людмилы Сергеевны» принято.

**1b Реакции на DLC:**
- Группа: `reactions.world.dlc_iceland` (или событие `world.dlc_new`) — первые 2–4 недели после релиза, потом `drop`. Срабатывание: первые встречи в сессии после выхода DLC.

**2 Мемы и кино:**
- Группа: `phrases.<actor>.memes` (внутри общей болтовни, weight ниже обычной — 0,3–0,4, мемы менять по мере устаревания; поле `drop` без удаления файлов).
- Пометки [мем — заменяемо] / [кино — вечное] при переносе в json НЕ переносить — это служебные пометки черновика; вести отдельный список мемных реплик для плановой замены (раз в квартал проверять актуальность).

**Проверки перед интеграцией:** Grep дословных вставок по живому эфиру; сверка произношений городов с официальной локализацией SCS (когда выйдет); мат — чистый, по регламенту; длина всех реплик в пределах 5–15 слов; теги → английские при переносе.
