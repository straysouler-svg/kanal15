# Черновик: отбивки «мультивопрос» — «по одному, рация не телеграф»

2026-11-11, Летописец; обновлено 2026-11-12 (вторая отбивка на каждое настроение — решение пользователя «отбивок побольше, хотя бы две на каждое настроение»). До одобрения; в level3_eleven.json не интегрировать, озвучку не запускать.
Механика: игрок задаёт несколько вопросов одной репликой; водитель отвечает на первый и добавляет короткую добродушную отбивку про остальные. Тон по решению пользователя — отмашка, не нравоучение: «по одному давай, рация не телеграф».
Ключи пулов: `player.one_at_a_time.<actor>`; у каждой реплики поле `mood` (cheerful / calm / tired / grumpy — ключи из bonds.py). На каждый mood у актёра ДВЕ реплики: `a` и `b`.
Длина: 3–12 слов (с ремарками), разговорная рация. Ловушки ударений избегаются: «по одному», «по очереди», «не сбивайся», без омонимов типа замок/замок.
Обращения БЕЗ «Железяки» (решение пользователя 12.11): нейтральные, по характеру («братан», «коллега», «сынок», «милый» и т.п.).

## Заметки для интеграции (не для эфира)

- На каждый mood у актёра две реплики (a — первая, b — вторая), итого 18 актёров × 4 mood × 2 = 144. Вторая реплика не повторяет первую ни формулировкой, ни приёмом (первая обычно про «по одному», вторая — про очередь/регламент/работу актёра).
- Все реплики короткие (4–12 слов с ремарками), длиннее 12 слов нет; без омонимов-ловушек для TTS («по одному», «по очереди», «по ноте» — ударения однозначны). Польские вставки у Янека латиницей — как в живом эфире.
- Теги расставлены по движку; у soroka (XTTS) ремарок смеха нет намеренно.
- У молодёжи (Стас, Бахти, Витёк) отбивка обыгрывает «быстроту» как черту характера; у ночных (Тень, Сова) — тишину и неторопливость; у Палыча — службовую лексику.
- Обращения без «Железяки» (решение 12.11): только нейтральные, по характеру актёра.
- Открытый вопрос пользователю: нужен ли общий пул-фолбэк для актёра без подходящего настроения или механика гарантирует mood у каждого.
