# Черновик: «А ты на чём?» — проверка игрока по телеметрии

2026-11-09 (правка 2: lie → misheard, по дизайн-решению пользователя), Летописец. До одобрения; озвучка — отдельный этап Механика.
Механика: водитель рассказал про свою машину (интент truck) → спрашивает игрока → STT ответ → сверка марки с телеметрией (точная марка/модель) → исходы. Канон машин — CHARACTERS.md + истории владения (раздел ниже). Реплики 5–15 слов.

Ключи пулов: `truck_check.ask.<actor>`, `truck_check.match.<actor>`, `truck_check.misheard.<actor>`, `truck_check.unknown.<actor>`, `truck_check.changed.<actor>`.

## Правки этой версии

1. **Ветка lie УДАЛЕНА. Вместо неё — misheard («ослышался эфир»).** Реальный кейс — whisper косящий марку («рено» → «реально», «ман» → «мам»). Игрок не врёт — врёт рация. Водитель смеётся НАД ЭФИРОМ/СОБОЙ, повторяет услышанную чушь, сам поправляется по телеметрии. Жёстких обвинений нет на всех уровнях дружбы.
2. Пул `truck_check.changed` — реакция на смену машины игрока.
3. Теги настроения (стиль mood_mark 1.33): (mood:good) — шутит, (mood:grumpy) — сухо буркнет, (mood:annoyed) — коротко отмахнётся.
4. Истории владения (канон от пользователя): student — аренда (врёт маме, что свой); bahti — кредит; boroda — лизинг на выкуп; lastochka — выкуп после лизинга; vera — фирменная. У этих актёров в ask — вариант «а у тебя свой или аренда?».

## Заметки для Механика

1. **Ключи:** `truck_check.ask.<actor>` (в конце интента truck, не чаще 1 проверки за встречу), `truck_check.match.<actor>`, `truck_check.misheard.<actor>`, `truck_check.unknown.<actor>`, `truck_check.changed.<actor>`.
2. **Misheard — виноват эфир, не игрок** (решение пользователя): водитель повторяет услышанную чушь, смеётся НАД РАЦИЕЙ/СОБОЙ, сам поправляется по телеметрии. Обвинений игроку нет.
3. **Настроение:** у match/misheard/changed по 2 варианта — (mood:good) и (mood:grumpy); у части есть (mood:annoyed) — самый короткий. Выбор по текущему mood актёра (как mood_mark 1.33).
4. **Словарь марок для STT — чем шире, тем реже misheard.** Синонимы: на скании/на мерсе/на мане/на дафе/на вольво/на рено/на ивеко + нормализация («реально»→рено, «мам»→ман, «дав»→даф, «наверняка»→«на мерсе»). **При уверенном совпадении по словарю misheard НЕ запускать** — идём в match.
5. **Changed:** сравнение с запомненной маркой из bonds/world_state. Первый раз changed не выпадает (не с чем сравнивать). Кулдаун: не чаще 1 раза за игровой день.
6. **Ask с владением:** «свой или аренда/лизинг/конторский» — только у student, boroda, lastochka, vera, rustam, bahti. Ответ игрока можно запоминать в bonds.
7. **Спец-кейс:** match у Стаса и Бахтияра при марке MAN — вариант «у меня тоже».
8. **Тишина Тени:** его пулы самые короткие; громкость ниже, паузы длиннее.
