# Настройка постинга в VK (один раз, ~15 минут)

Делает пользователь в браузере. Штурман проверяет пост сам.

## Шаги

1. Создать сообщество: vk.com → «Сообщества» → «Создать сообщество» → тип **«Группа»** (не публичная страница — в группе проще модерировать и постить от её имени).
   - Название: «Канал 15 — мультиплеер для интровертов» (Штурман потом оформит аватар, обложку, описание).
2. Получить ключ доступа сообщества:
   - В группе: **Управление → Работа с API → Ключи доступа → Создать ключ**.
   - Права: **управление сообществом, стена, фотографии, видео, документы**.
   - Подтвердить с телефона. Скопировать ключ.
3. Узнать ID группы: **Управление → в адресной строке** `vk.com/clubNNNNN` — число NNNNN. Или «Управление → Основная информация → ID».
4. Положить два файла:
   - ключ → `G:\Claude\gruzovichki\promo\vk\token.txt` (одной строкой)
   - ID → `G:\Claude\gruzovichki\promo\vk\group_id.txt` (только число)
   (Оба в .gitignore — в git не уйдут.)
5. Сказать Штурману «готово» — он сделает тестовый пост и предложит его глазами, потом удалит.

## Что умеет скрипт (post_vk.py)

- Текстовый пост от имени группы: `wall.post`.
- Пост с фото (обложки статей).
- Пост с видео (шортсы — вертикаль VK сам подхватывает в клипы).

## Квоты и заметки

- Лимиты VK мягкие: десятки постов в день не проблема.
- Видео до ~4 ГБ и 4 часов — наши минутные шортсы проходят без вопросов.
- Если ключ протухнет (VK иногда рвёт ключи сообщества при смене пароля) — повторить шаг 2.
