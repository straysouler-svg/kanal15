# Настройка автопостинга Reels в Instagram (один раз, ~30 минут)

Делает пользователь в браузере. Meta в РФ заблокирована — весь процесс через VPN.
Мета признана в РФ экстремистской организацией: рекламу не покупаем, только постинг (канон проекта).

## Шаги

1. Аккаунт Instagram «Канал 15» → перевести в **профессиональный** (Настройки → Тип аккаунта → Business или Creator).
2. Создать **Facebook-страницу** (пустую, любое название «Канал 15») и привязать к ней IG-аккаунт
   (IG → Настройки → Связанные аккаунты → Facebook).
3. https://developers.facebook.com/ → «Создать приложение» → тип «Бизнес».
4. В приложении добавить продукт **Instagram Graph API**.
5. Получить токен: Graph API Explorer → выбрать своё приложение → «Generate Access Token»
   с правами: `instagram_basic`, `instagram_content_publish`, `pages_show_list`, `pages_read_engagement`.
   Войти своим FB-аккаунтом (тем, куда привязан IG).
6. Продлить токен до долгоживущего (60 дней): Штурман сделает скриптом по короткому токену —
   положи короткий в `promo/instagram/token.txt`, он заменит на длинный.
7. Узнать **IG User ID** (число): Штурман вытащит API-запросом по токену,
   либо вручную — положи в `promo/instagram/ig_user_id.txt`.
8. Сказать «готово» — Штурман сделает тестовый Reel (черновик), покажет, опубликует по слову.

## Ограничения

- 25 постов с медиа в сутки через API — нам нужно 2.
- Reels: 3 сек – 15 мин, mp4, вертикаль 9:16 — наши шортсы проходят.
- Для постинга на СВОЙ аккаунт ревью Meta обычно не нужно (стандартный доступ).
