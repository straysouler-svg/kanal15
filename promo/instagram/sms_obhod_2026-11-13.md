# Как пройти подтверждение личности Facebook/Meta без российской СМС (13.11.2026)

Проблема: Meta требует подтвердить личность для связки Facebook↔Instagram (нужна для
Instagram Graph API), СМС на российские номера не доходят.

## Главная новость: SMS-Activate закрылся (конец 2025)

Искать альтернативы. Рабочие на 2026: **CodesSender** (от $0.20, заявляют реальные
SIM, не VoIP — важно, Meta отбраковывает виртуальные диапазоны), 5sim, Hero-SMS,
SMSPVA, SMSFAST, anosim. Пополнение из РФ: крипта / карты СНГ.

## План А — виртуальный номер на реальной SIM (основной)

1. Зарегистрироваться на CodesSender (или Hero-SMS), пополнить на ~$2–3.
2. Выбрать сервис «Facebook», страну — **ту же, что IP VPN** в момент подтверждения
   (если VPN США — номер США; так меньше антифрод-трения). Брать дороже, «реальная SIM».
3. Включить VPN на ту страну, открыть facebook.com в чистом профиле браузера,
   пройти подтверждение, вбить купленный номер, получить код, ввести.
4. Если СМС не пришла — деньги за активацию возвращаются, берём другой номер/страну
   (часто заходят: Казахстан, Киргизия, Индонезия).
5. **СРАЗУ после прохождения:** привязать TOTP-аутентификатор (Google Authenticator /
   Яндекс.Ключ) и сохранить резервные коды. Купленный номер уйдёт в перепродажу —
   кто-то другой сможет сбросить пароль по нему. После привязки TOTP номер отвязать
   или заменить.

## План Б — без номера вообще (проверить первым, бесплатно)

- На экране подтверждения пощёлкать варианты: иногда Meta предлагает **код в WhatsApp**
  (WhatsApp у нас живой, российский номер там работает) или **видео-селфи**.
- Если есть выбор «подтвердить через email» — подтвердить почту, иногда этого хватает,
  чтобы отпустило.

## План В — чужой живой номер

- Попросить знакомого с НЕроссийской симкой (KZ/BY/ARM/GEO/сербская eSIM) принять одну СМС.
  Самый надёжный вариант по антифроду, бесплатно. Потом то же самое: TOTP, номер отвязать.

## После прохождения (любым путём)

1. Instagram-аккаунт → профессиональный (Creator) → привязать к Facebook Page.
2. developers.facebook.com → наше приложение → добавить Instagram Graph API,
   скоупы instagram_basic, instagram_content_publish, pages_show_list.
3. Получить long-lived token (60 дней, продлевается) → `promo/instagram/token.txt`.
4. Скрипт `promo/instagram/upload_reel.py` уже ждёт токен.

## Риски

- Купленный номер — чужой завтра: без отвязки/TOTP аккаунт уязвим к сбросу пароля.
- Частые попытки с разных номеров подряд могут усугубить блок — пауза 10–15 мин между попытками.
- VPN-IP и страна номера должны совпадать, иначе антифрод Meta заворачивает чаще.
