# Настройка автозагрузки шортсов на YouTube (один раз, ~20 минут)

Делает пользователь в браузере (там нужен его Google-аккаунт канала «Канал 15»).
Штурман потом проверит загрузку сам.

## Шаги в Google Cloud Console

1. Открыть https://console.cloud.google.com/ (войти тем Google-аккаунтом, на котором канал «Канал 15»).
2. Сверху слева — создать проект: имя `kanal15` (любое).
3. Меню → «API и сервисы» → «Библиотека» → найти **YouTube Data API v3** → «Включить».
4. «OAuth consent screen» (экран согласия):
   - Тип: **External** → «Создать».
   - Имя приложения: «Канал 15 загрузчик» (покажется только тебе при входе).
   - Почта разработчика — твоя.
   - Scopes: добавить `.../auth/youtube.upload`.
   - Test users: **добавить свою же почту** — без этого вход не пустит.
5. «Credentials» → «Создать учётные данные» → **OAuth client ID**:
   - Тип приложения: **Desktop app**, имя любое.
   - Скачать JSON → переименовать в `client_secret.json` → положить в `G:\Claude\gruzovichki\promo\youtube\`.
   (Файл уже в .gitignore — в git не уйдёт.)
6. Сказать Штурману «готово» — дальше он: первый запуск откроет браузер, надо будет
   нажать «Продолжить» (Google предупредит «приложение не проверено» — это наш собственный
   клиент, жмём «Advanced → Go to …»), вход сохранится в `token.json` навсегда.

## Квоты (чтобы не удивляться)

- Бесплатная квота API: 10 000 единиц/сутки; одна загрузка видео = 1600 единиц.
  Т.е. ~6 шортсов в день — нам за глаза.
- Статус «External + не проверено» ограничивает публикации? Нет: загружать можно,
  ограничение только на количество тест-пользователей (100) и плашку при входе.

## После настройки

Глашатай заливает так (через Штурмана):
```
build/venv/Scripts/python.exe promo/youtube/upload_short.py promo/shorts/candidates_2026-11-12/short3_net_dannykh.mp4 \
  --title "… #Shorts" --description "…" --tags "ets2,канал 15,мультиплеер для интровертов" --privacy unlisted
```
По умолчанию --privacy unlisted (ссылка есть у нас, в поиске не видно) — после глазной
проверки переключаем на public в студии или заливаем сразу public по явному слову пользователя.
