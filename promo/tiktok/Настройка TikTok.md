# Настройка автозагрузки в TikTok (один раз, ~30 минут + ревью TikTok)

Делает пользователь в браузере. Всё через VPN с регионом НЕ РФ (TikTok заблокирован в России — и аккаунт, и кабинет разработчика).

## Шаги

1. Завести аккаунт TikTok для «Канал 15» (через VPN). Имя близкое к канону: @kanal15 (что свободно).
2. Зайти на https://developers.tiktok.com/ → войти этим аккаунтом → «Manage apps» → «Create an app».
3. В приложении: добавить продукт **Content Posting API**. Заполнить базовые поля (иконка, описание — «загрузка своих роликов на свой аккаунт»).
4. Пройти авторизацию с токеном: в приложении есть «Generate access token» (sandbox/тестовый) — scope **`video.upload`**.
   - Скопировать access token → `G:\Claude\gruzovichki\promo\tiktok\token.txt` (одной строкой, в .gitignore).
   - Токен живёт 24 часа + refresh token на год — Штурман добавит авто-продление, когда будет refresh token (положить рядом в `refresh_token.txt`).
5. **Ревью**: пока приложение не одобрено TikTok, ролики публикуются только ПРИВАТНО (видишь только ты).
   Для public подать app на проверку («Submit for review», scope video.upload) — обычно несколько дней.
   После одобрения Штурман переключит скрипт на публичный режим.

## Ограничения

- До 6 постов в сутки на аккаунт через API (нам нужно 2).
- Видео: 3 сек – 10 мин, вертикаль — наши шортсы проходят.
- Пометка ИИ-контента: голоса синтезированы — в описании профиля пишем «голоса сделаны нейросетью» (правило из контент-плана).
