# Обращение к стримерам — приглашение на тест (07.11.2026)

Универсальный текст: без имени, подходит для личных сообщений, почты и комментариев.
Ссылка ведёт на общий установщик (публичный канал, водители зовут игрока без имени).

---

Привет! Меня зовут Дмитрий, я делаю «Канал 15» — рацию для одиночной игры в Euro Truck Simulator 2. Мы называем её «мультиплеер для интровертов». Приглашаю тебя на тест 🙂

**Что это.** По трассе вместе с тобой едут 17 водителей-персонажей. У каждого свой рейс по настоящей бирже грузов из твоего сохранения, своя кабина, музыка и характер: Михалыч со своей «Старушкой», Самарканд с пловом на каждой стоянке, Кинолог с овчаркой Графом, рокер Кардан. Слышно только тех, кто рядом, как на настоящей рации.

**Что можно делать:**
• отвечать им голосом с кнопки на руле: «кто в эфире?», «как дорога?», «где поесть?», «расскажи анекдот»;
• дружить: водители помнят тебя между поездками, у каждого своё настроение на день, а нагрубишь — обидится;
• получать голосовые от бухгалтерии своей компании за каждый штраф;
• слышать, как твои наёмные водители выходят в эфир, когда едут мимо;
• здороваться с проезжими иностранцами — отвечают на своём языке и со смехом.

**Для стрима:** есть готовый оверлей для OBS — кто в зоне рации, сердечки дружбы и субтитры всего, что говорят в эфире. Для горизонтального и вертикального стрима.

Бесплатно, интернет в игре не нужен, обновления приходят сами. Один установщик, он сам найдёт игру и предложит выбрать кнопку рации на руле:
https://storage.yandexcloud.net/kanal15-updates/channels/public/Kanal15-Setup-v1.24.exe
